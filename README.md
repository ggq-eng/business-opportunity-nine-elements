## 📌 简介

商机九要素企业调研与Excel生成技能。当用户提供一批企业名单（Excel、截图、文本均可）并要求输出「商机九要素」（对接角色/合作主体/客户业务/目标场景/采购时间/项目进度/竞品/预算/使用AI经验）时使用。适用于销售售前、To B 商机梳理、客户画像分析场景。核心流程：逐一检索企业公开信息（工商/官网/年报/新闻）→ 区分「已核验事实」与「销售侧推断（标注待确认）」→ 用 openpyxl 生成两表结构 Excel（商机九要素 + 填表说明与数据来源）。

## 📖 使用说明（完整规范）

## Overview

将企业名单转化为结构化的「商机九要素」Excel。调研每家企业可公开查证的信息（统一社会信用代码、法人、注册资本、成立日期、行业、注册地址、参保人数、主营业务、营收），并基于行业特征推断销售侧字段（目标场景、预估账号数、竞品、预算区间、AI 使用经验），所有推断项必须标注【建议/待确认】等标记，最后生成样式化 Excel。

## 输出结构（11 列）

固定表头（顺序不可变）：

1. 序号
2. 公司名称
3. ① 对接角色身份（建议）
4. ② 合作主体（企业工商信息，已核验）
5. ③ 客户业务概况（人员/业务/营收）
6. ④ 计划实现的目标场景（WorkBuddy价值 + 预估账号数）
7. ⑤ 预计采购时间
8. ⑥ 项目进度
9. ⑦ 竞品（可能对比，待确认）
10. ⑧ 预算
11. ⑨ 使用AI的经验

第二个 Sheet「填表说明与数据来源」：说明字段可信度分级、重要口径提示、数据来源与检索日期、下一步建议。

## 字段可信度规则（关键）

- **②合作主体**：必须可核验。统一社会信用代码、法人、注册资本、成立日期、行业、注册地址，来源为天眼查/企查查/爱企查/启信宝等公开工商信息。
- **③客户业务概况**：人员以「参保人数/公开规模」为准；部门人数为合理推断需标注「待核实」；营收以上市公司年报或公开口径为准；未披露则写「未披露」。
- **①④⑦⑨**：为销售侧推断，必须带【建议/可能对比/待确认】标记。
- **⑤⑥⑧**：属商机推进内部信息，默认「待确认/调研」，除非用户提供实际信息。
- **人员口径差异**：深圳企业普遍存在「社保参保人数」与「官网/集团宣传人数」不一致，必须双标注并注明差异原因（如轻资产研发平台、异地制造基地、外包团队等）。
- **同名主体**：注意区分上市公司与同名不同主体（如「芯海微电子」≠「芯海科技688595」），在表格中明确标注。

## 工作流程

1. **读取名单**：从用户提供的 Excel（openpyxl 读取）/截图（OCR 或按名称逐个检索）/文本中提取公司名称清单。
2. **逐一调研**：每家公司做 1 次网络检索（公司全名 + 行业/规模/营收关键词），上市公司优先查年报/季报口径，非上市查工商平台 + 官网 + 招聘平台。
3. **组织数据**：按 11 列结构填写，遵守字段可信度规则。
4. **生成 Excel**：运行 `scripts/build_nine_elements.py`（见下方说明），或直接内联 openpyxl 代码。样式要点：深蓝表头（1F4E78）、微软雅黑字体、自动换行、列宽 [5,26,22,34,46,46,16,14,30,24,30]、行高 150、冻结窗格 C2。
5. **输出文件**：保存到源文件所在目录（通常为桌面），命名「源文件名_商机九要素.xlsx」，用 present_files 呈现。

## 脚本

`scripts/build_nine_elements.py` 提供了完整的 Excel 生成模板（含样式与双 Sheet 结构）。使用方式：

- 复制脚本到工作目录，将 `rows` 列表替换为实际调研数据（每项含 name/role/entity/biz/scene/time/stage/rival/budget/ai 十个字段）。
- 所有字符串值建议使用三引号 `"""` 包裹，避免内容中的引号破坏 Python 语法（本技能开发时踩过此坑）。
- 运行：`python build_nine_elements.py`，输出文件名在脚本末尾 `out` 变量中修改。

## 常见陷阱

- **引号转义**：调研内容中常含「小巨人」「AI+实验室」等带引号词，用中文引号「」或三引号包裹，勿用 ASCII 双引号直接嵌字符串。
- **参保人数为 0**：可能是纯控股/投资平台或轻资产公司，不要直接判定为无员工，需结合官网/集团口径说明。
- **上市公司营收**：以最新年报为准，注明年份；同比数据有助于判断客户规模与预算能力。
- **AI 经验推断**：从事 AI/机器人/算力的公司（如优艾智合、协创数据）标注【较积极】；传统制造标注【待确认】；有公开报道已用 AI（如律所办过 AI 讲座）标注【有认知】。
